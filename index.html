Supported Feedback Types:

  • PRICING: Start with lot name (containing AMZ_), then list ASINs with manifest and correct prices
  • DEEP SKU: Start with "DEEP SKU", then Pallet ID, Item #, Description, Quantity, Percentage
  • DEEP SKU (spreadsheet rows): Paste tab-separated rows directly — auto-detected when the first cell looks like an item number (e.g. LPLX…). Expected columns: Item# · Seller Category · Description · Qty · Unit Price · Extended Retail · Brand · UPC · … · Pallet ID · Subcategory · Lot ID. Percentages are calculated automatically from Column F (Extended Retail) ÷ lot total retail.
  • RETAIL RANGE: Start with "RETAIL RANGE MIN/MAX/CONTRACT/PALLET", then relevant values
  • LOTTING: Start with "LOTTING", then max allowed, actual total, and categories with counts
